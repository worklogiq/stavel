This is an illustrative decision aid, not an implemented language rule pack. Align choices to actual accepted repository conventions before generating files.

Decide framework, composition, navigation, design system, forms, state/data fetching, localization, accessibility, error recovery and stable test targets.

Record applicability, owner, actual commands, selected tools, supported versions, unresolved questions and acceptance evidence. General framework requirements remain portable; a profile does not mandate a provider or application stack. Use the [profile contribution contract](../contribution-profiles.guide.md).
