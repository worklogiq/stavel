The [package requirements](./framework.requirements.md) and [package design](./framework.design.md) define the shared framework contract. The [CLI contract](../../../../public/framework-cli.contract.md) remains its canonical public interface document.

[Skill capability designs](../../capabilities/skill/guided-workflows/index.md) reference these owners; a feature packet must not silently replace package-wide requirements or manufacture acceptance from generated files.
