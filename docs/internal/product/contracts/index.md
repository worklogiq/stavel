These topic directories own shared obligations and interfaces used by [capabilities](../capabilities/index.md). Keep one canonical definition and link it from dependent designs. A contract-topic directory can include its defining requirements and design; document kind remains distinct from its hierarchy role.

- [Framework](framework/index.md): package-wide behavior and architecture.
- [Distribution](distribution/index.md): dependency snapshots and delivery boundaries.
- [Repository configuration](configuration/index.md): draft committed settings, decision provenance and early shared resolution.

Existing curated public contracts can remain at their mapped canonical homes and be linked here. Contract placement does not imply that every product must adopt an API protocol, tenancy model or provider.
