## Authority and fixed choices

The [recon UX-01 through UX-34](./guided-setup-and-repair.recon.md#confirmed-user-choices) records actual user decisions and their sources. This register owns proposed architectural choices for the [requirements](./guided-workflows.requirements.md); its draft state does not revoke those settled choices. The current user request authorizes preparing this packet, not selecting every recommendation below.

Fixed choices include bare commands with optional scope overrides, root discovery with questions for ambiguity, terminal and agent Q&A sharing an engine, doctor findings followed by a repair preview, agent-led semantic review through the skill, discoverable help, scoped structured customization, task-local defaults unless a standing rule is stated, macro tracking, STRICT MODE and execution closure. The owner subsequently endorsed incremental PLAN, EXECUTE using STRICT MODE with explicit PLAN/DESIGN transitions for missing preparation, distinct VIBE iteration and EXPLORE as discovery/recon. UX-21 through UX-24 record that direction; exact D-13/D-14 mechanisms remain unresolved.

## Local defaults and reusable packs


Repository/task-owned customization is the proposed first delivery boundary. Keep its record format suitable for reuse; distribution through team/community packages requires a later explicit compatibility, trust and delivery contract. This distinction does not omit the required local augmentation behavior.

## Consequences and enforcement

Once resolved, amend the owning requirements/design/CLI/configuration contracts and their tests in the affected slice. New upstream guidance must not overwrite accepted adopter amendments. Doctor can check structural conflicts; the agent reviews whether changes preserve required behavior and intended ownership. Keep rejected alternatives and supersession reasons here, with replacement links if decisions change.

## Accepted execution resolution

The owner accepted the eight consolidated execution choices, including a scoped chat-reviewed design baseline, and required warnings for AI-assisted nondeterministic migrations/repairs.
