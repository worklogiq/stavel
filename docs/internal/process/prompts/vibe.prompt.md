VIBE combines the development activities in short authorized iterations: explore intent/code, experiment or learn when useful, capture design decisions, plan the next coherent change, execute it and review the result. It is a combined workflow, not a waiver of philosophies or preservation/verification obligations.

Maintain durable intent during the work. Record material choices with actual sources and acceptance state; update the relevant design, plan/slice and status at meaningful iteration/handoff boundaries. Use proportional records rather than a full packet per tiny edit. Do not reconstruct all decisions only at session end or accept an idea merely because code was written.

Apply accepted requirements, local conventions and STRICT MODE fidelity obligations during code changes. If new information changes a material contract, make the decision explicit and reconcile affected design/planning and the selected review policy. A hypothesis may use EXPERIMENT; every iteration need not contain an experiment.

Respect the task's chosen story flow: stories can guide exploration/design or emerge from planning when useful. Retain a coherent verified stopping point and report actual checks, unresolved alternatives and remaining scope. VIBE still honors the substantial-feature design-review gate or an actual scoped exception.

When a VIBE iteration includes PLAN, ask about output stories for that planning scope unless already answered or configured always/never. Use the selected repository story template; do not repeat a settled question at every tiny iteration.

Result: iterated product behavior with contemporaneous decisions/design/execution context and truthful verification, ready for another iteration or a durable handoff.

Design PRs are recommended by default for substantial work, not a forced lifecycle gate. Honor an explicitly required repository policy, but otherwise the user may go directly from DESIGN to PLAN or design a small story. Record selected design separately from actual review/acceptance; never invent PR approval or require ceremonial permission for a chosen authorized path.
