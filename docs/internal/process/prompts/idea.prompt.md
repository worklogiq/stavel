Capture a short thought without starting exploration, design or implementation. Preserve the user's original text and source; infer the existing feature/capability owner from accepted mappings and current work, asking only if placement is genuinely ambiguous.

Use the packaged idea command with the selected target/capability, optional title and stable request ID for retries. It uses the shared checked capture operation to write one small recon record and register the idea in the capability-owned work file. The work registry remains pointers only. Preview/dry-run writes nothing; do not silently initialize a missing adopted setup or overwrite custom mode vocabularies.

Return the idea ID and record link. No story questionnaire, design packet, implementation or automatic phase promotion is part of capture. Later EXPLORE/DESIGN/PLAN work retains the work identity and original idea source. IDEA grants no Git, publication, dependency installation or external-message authority.
