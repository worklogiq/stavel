## Scope and applicable target

Identify the real surfaces, user tasks, accessibility target and explicit non-applicability. Visual interfaces, terminal tools and SDKs have different relevant checks.

## Interaction and recovery

For applicable visual surfaces record semantics, focus order, keyboard alternatives, labeling, error announcements, zoom, contrast and motion. For terminal/SDK surfaces record accessible help and usable output/error behavior.

## User and technology coverage

State user needs, assistive-technology/browser/platform coverage and manual review boundaries without inventing universal targets.

## Evidence and gaps

Link automated and manual checks, observed results, unsupported combinations and accountable follow-up work.
