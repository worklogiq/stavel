Store accepted architectural and policy decisions here, or route to the project's existing decision directory in the [profile](../dev/project-profile.overview.md). Use the [decision template](../templates/design/decision.template.md). An index is not a requirement to invent decisions before they exist.

Each record states context, options, decision, authority, consequences, affected contracts, and supersession. Keep rejected options available as reasoning; they do not remain active policy.

The [Stavel restart decision](stavel-restart.decision.md) defines the current product identity, version, branch and compatibility boundaries.
